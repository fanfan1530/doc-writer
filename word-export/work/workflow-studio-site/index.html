02 / DOCUMENT SUITE

常用文书类型保持可见，生成前就能确认覆盖范围。

DOC 01Penalty

行政处罚决定书

提炼事实，写明涉嫌罪名或违法行为，保持决定书正式语气。

DOC 02Inspection

身体检查笔录

正文与照片分离，照片页按标准模板独立排版。

DOC 03Identify

辨认笔录

保持原模板结构，替换笔录中的对应字段。

DOC 04Entry

入所材料

生成六份 Word；固定告知书和知识材料可直接输出。

DOC 05Record

前科证明

按标准证明模板保留格式，替换姓名、身份和证明内容。

DOC 06Archive

模板档案

模板集中管理，输出结果保持可复查、可归档。
